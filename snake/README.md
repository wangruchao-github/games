# 贪吃蛇 Snake

单文件、零依赖的贪吃蛇小游戏。直接双击 `index.html` 就能玩（无构建、无 npm）。

## 玩法

| 操作 | 按键 |
| --- | --- |
| 移动 | `↑` `↓` `←` `→` / `W` `A` `S` `D` / 在画布上滑动 / 手机端方向键 |
| 暂停 | `空格` |
| 重开 | `R`（或点「开始游戏 / 再来一局」按钮） |

- 吃到红色果实 +1 分，蛇身变长，速度随之提升（145ms/步 → 最快 65ms/步）。
- 撞墙或撞到自己即结束。勾选「穿墙模式」后从对侧穿出，但撞自己依然会死。
- 最高分记录在 `localStorage`（key: `snake.best`），刷新不丢。

## 实现要点

- **网格** 20×20，格 24px，canvas 480×480，用 CSS `aspect-ratio` 自适应缩放。
- **插值渲染** 逻辑走格、渲染走小数：`requestAnimationFrame` 里累加 dt，跨过 `stepMs` 才走一步，
  两帧之间按 `acc / stepMs` 线性插值，所以移动是平滑的而不是一跳一跳。
- **防自杀转向** 按键先进方向队列（上限 2），`step()` 消费时丢弃与当前朝向相反的方向，
  解决「同一 tick 内快速按两个键导致 180° 回头撞死」这个经典 bug。
- **速度** `stepMs = max(65, 145 - score × 3)`，线性提速但有下限，不会快到看不清。
- **食物生成** 拒绝采样直到落点不在蛇身上（带 1000 次兜底，避免满盘死循环）。
- **跟随渲染** 蛇头画渐变 + 眼睛，朝向跟随方向；食物做呼吸脉动。

## 测试

游戏逻辑跑在纯函数式的闭包里，用一个最小 DOM stub 把它从 `index.html` 里抽出来直接测：

```bash
node snake_test.mjs   # 需要先保存上面的测试脚本
```

24 条用例覆盖：初始状态、转向与 180° 拦截、计分/加长/提速/封顶、四向撞墙、撞自己、
穿墙模式（含环面下撞身体）、300 步随机对局的食物合法性、状态机与渲染冒烟。
