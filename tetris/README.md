# 俄罗斯方块 Tetris

单文件、零依赖的俄罗斯方块。直接双击 `index.html` 就能玩（无构建、无 npm、无网络）。

## 玩法

| 操作 | 按键 |
| --- | --- |
| 移动 | `←` `→`（含 DAS 自动连发） |
| 软降 | `↓`（按住，1 分/格） |
| 硬降 | `空格`（2 分/格） |
| 顺时针旋转 | `↑` / `W` / `X` |
| 逆时针旋转 | `Z` / `Ctrl` |
| 旋转 180° | `A` / `Q` |
| 暂存 Hold | `C`（每回合限一次） |
| 暂停 | `P` / `Esc` |
| 重开 | `R` |

手机端：屏幕下方有方向 / 旋转 / 硬降 / 软降 / 暂存按钮（按住可连发）；
棋盘上左右滑移动、下滑软降、上滑硬降、点按旋转。

最高分存在 `localStorage`（key: `tetris.best`），刷新不丢。

## 规则

- **棋盘** 10×20，上方额外 2 行缓冲区（生成和 SRS 旋转需要）。
- **发块** 7-bag 随机（每 7 个方块里 7 种各出现一次），预览 3 个。
- **旋转** 完整 SRS：J/L/S/T/Z 用一套踢墙表，I 用另一套，O 不踢。
  官方表是「y 向上」口径，加载时统一翻成屏幕坐标（y 向下）。
- **锁定延迟** 500ms，移动或旋转可重置计时器，上限 15 次；用满后想再拖就得等到锁定。
- **重力** 官方曲线 `(0.8 - (lv-1) × 0.007)^(lv-1)` 秒，下限 20ms；每满 10 行升 1 级，封顶 30 级。

### 计分

| 动作 | 分数（× 等级） |
| --- | --- |
| 单 / 双 / 三 / 四行 | 100 / 300 / 500 / 800 |
| T-Spin 0 / 1 / 2 / 3 行 | 400 / 800 / 1200 / 1600 |
| Mini T-Spin 0 / 1 / 2 行 | 100 / 200 / 400 |
| 软降 | 1 分/格 |
| 硬降 | 2 分/格 |

- **B2B**：连续做 Tetris（四行）或任意 T-Spin，再做一次难度动作，分数 ×1.5。被普通消行打断。
- **Combo**：连续消行时每次额外 `50 × combo × 等级`。
- **T-Spin 判定**用三角规则：T 的中心四个对角格里，实心 ≥3 个，且「正面两角都实」或「四角全实」算完整 T-Spin；
  3 角但正面只占一角算 Mini。墙和地板算实心。最后一步必须是踢墙的旋转才算（180° 不算）。

## 实现要点

- **形状靠算不靠写死**：每种方块只存一个「出生朝向 + 包围盒边长」，另外三个朝向由绕盒中心顺时针旋转
  推导（`(dx,dy) → (-dy,dx)`）。I/O 的包围盒是 4×4 / 2×2，同一套公式直接套用就对了。
- **180° 旋转拆成两次 90°**，每一步都走标准 SRS 校验。早期版本给 180° 单开了一条「只校验目标形态」的
  捷径，结果方块能从左墙穿出去 —— 变异测试抓到的。
- **碰撞允许 `y < 0`**：缓冲区之上不算碰撞，否则 SRS 旋转永远转不动（踢墙表里就有往上踢的项）。
  但 `x < 0 / x >= COLS / y >= ROWS` 必须显式判掉 —— `board[y][x]` 读到 `undefined !== 0` 会「碰巧」
  挡住 `y >= 0` 的越界，掩盖掉漏掉左墙判定的 bug，只有缓冲区那一段才暴露。
- **T-Spin 在方块写入棋盘之后判定**：四个对角格本来就不属于 T 自己，所以先落定再判不会自欺欺人。
- **锁定延迟与重力解耦**：`update()` 先走 DAS/ARR 和重力/软降，最后统一看「下面还能不能站」来决定
  锁不锁，逻辑比在重力分支里塞判断干净。
- **DPR 适配**：`fit()` 把画布物理像素设成逻辑尺寸 × dpr 并 `setTransform`；`resize` 时重建上下文。
- **消行动画 320ms**，期间不接受输入、不放新方块（`clearing` 非空时 `update` 直接早返回）。
- **音效**用 WebAudio 现场合成方波/三角波，首次交互时才建 `AudioContext`（避开自动播放限制）。

## 测试

游戏逻辑跑在闭包里，用一个最小 DOM stub 把它从 `index.html` 里抽出来直接测：

```bash
node tetris_test.mjs
```

86 条用例，分 11 组：形状与旋转自洽、踢墙表结构与 y 翻转、碰撞与移动（含缓冲区边界）、
7-bag、暂存、T-Spin 三角规则（4 个朝向 × 完整/mini/不成立）、消行与计分（分数/B2B/Combo/等级/行压实）、
硬降软降与锁定延迟、状态机、确定性长跑压力测试、渲染冒烟。

测试是**确定性**的：自己的 PRNG 选操作序列，重开时用 `seed()` 把方块序列也钉死 —— 早期版本用
`Math.random()`，同一次回归只有约 50% 概率被抓住。棋盘夹具用 `setBoard()` 加载，它会拒绝宽度不是 10
的字符串行（手写 10 列字符串很容易数成 9 个）。

**变异测试**验证过断言不是摆设：往源码里注入 23 个缺陷（SRS 不翻 y、7-bag 退化成纯随机、去掉 B2B 加成、
锁定重置不封顶、压实行方向反了、碰撞漏墙漏地板、ghostY 少算一格、生成时不判死、hold 不限次数……），
**23/23 全部被测试抓住，0 漏过**。脚本已清理，需要时可照着上表重写。
