# 坦克大战 Battle City

单文件、零依赖的坦克大战。直接双击 `index.html` 就能玩（无构建、无 npm、无网络）。

## 玩法

| 操作 | 按键 |
| --- | --- |
| 移动 | `↑` `↓` `←` `→` / `W` `A` `S` `D` / 手机端方向键 / 画布上滑动 |
| 开火 | `空格` / `J` / `K`（手机端「开火」按钮，点屏幕任意处也能开火） |
| 暂停 | `P` |
| 重开 | `R` |
| 静音 | `M` |

**守住底部老巢，消灭全部敌军。** 老巢被打掉或坦克全部耗尽即失败；通关一关奖励 1 条命。
共 5 关，最高分存在 `localStorage`（key: `tank.best`）。

## 地形

| 符号 | 地形 | 作用 |
| --- | --- | --- |
| 砖墙 | 棕 | 挡坦克，子弹一发打掉一格；玩家 2 星以上一发清 2×2 |
| 钢墙 | 灰 | 挡坦克，子弹打不动；只有玩家 3 星能打穿 |
| 水 | 蓝 | 挡坦克，子弹照过 |
| 树 | 绿 | 完全不挡，**盖在坦克上面**（经典掩护） |
| 冰 | 浅蓝 | 不挡，但坦克松手后还会继续滑行到撞墙 |
| 老巢 | 鹰 | 被打中立即游戏结束 |

## 敌军

| 类型 | 血量 | 速度 | 分值 | 出现关卡 |
| --- | --- | --- | --- | --- |
| 普通 | 1 | 1.0 | 100 | 第 1 关起 |
| 快速 | 1 | 2.0 | 200 | 第 2 关起 |
| 火力 | 1 | 1.0 | 300 | 第 3 关起（开火极快） |
| 重甲 | 4 | 1.0 | 400 | 第 4 关起（每掉一格血变浅一度，一眼看出快破了） |

同屏最多 4 辆，顶部 3 个出生点轮转，出生瞬间有 40 帧无敌闪烁。
玩家阵亡后残余敌军会直接退场（原版机制），不然老巢会被趁虚而入。

## 道具

击毁敌军有 20% 概率掉落，开车压上去拾取（限时，最后 300 帧闪烁提示快过期）：

- **星星** 火力 +1（最高 3 星：弹速↑ → 双发子弹+砖墙连片 → 能打穿钢墙）
- **头盔** 10 秒护盾，子弹被吸收
- **铁锹** 15 秒内老巢围墙变钢墙
- **手雷** 全屏清场
- **定时** 8 秒冻结敌军
- **加命** 生命 +1

## 实现要点

- **网格** 26×26，格 20px，画布 520×520。坦克 16×16 —— 比格子小，所以在 1 格宽的走廊里不用对齐也能自由穿行（这正是原版坦克能钻窄道的原因）。
- **碰撞** 纯 AABB 逐像素判定，坦克/子弹分两轴独立判定（可以贴着墙角斜着蹭过去）。地图外视为钢墙，天然封边。
- **固定步长** 60Hz 累加器，主循环只做逻辑，渲染独立；掉帧最多补 3 步防止"追帧雪崩"。
- **分层渲染** 地形画在离屏 canvas（仅在砖墙被打破时重画），树丛画在第二张离屏 canvas 上**最后**贴出，坦克夹在中间。
- **关卡是数据** 5 张 26×26 的 ASCII 地图字符串，生成脚本带左右镜像 + 尺寸断言。
- **音效** WebAudio 现场合成（开火方波、爆炸白噪声），首次交互时才建 AudioContext，`M` 或勾选框可静音。

## 测试

游戏逻辑跑在闭包里，测试用最小 DOM stub 把闭包抽出来直接驱动：

```bash
node tank_test.mjs
```

47 条用例，分 10 组：地图完整性、地形碰撞、边界、移动、子弹（砖/钢/水/护盾/对撞/友伤免疫）、
敌军（血量/出生点/上限/出场无敌/冷却）、道具、老巢与失败条件、冰面惯性、渲染冒烟、平衡回归。

最后两条平衡回归是用"机器人"跑出来的：

- **无人操作时老巢至少撑 8 秒** —— 这条是被真实 bug 逼出来的：早期版本中间出生点的敌军两发就能把老巢端了，玩家站着不动 4 秒就输。
- **不死瞄准 bot 多次尝试能清空第 1 关** —— 验证关卡在结构上可通关（12 局里目前能过 3~7 局，失败的都是老巢被推，而 bot 完全不懂守家）。

> bot 只用来证明"关卡能过"，不代表难度评价 —— 它不会守家、不会躲弹、路径规划很笨。
